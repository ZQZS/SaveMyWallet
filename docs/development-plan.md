# 开发计划

当前优先维护 Windows 和安卓的离线账本同步。Android 真机回归覆盖同步和手动备份迁移。DeepSeek 助手的下一步是在两端用测试密钥核对实际识别结果。应用内桌宠可在同一批设备上独立验收。[开发里程碑](milestones.md)

## 近期工作

| 工作项 | 实施步骤 | 完成时可检查的结果 |
| --- | --- | --- |
| 双端离线同步验收 | 从同一云端基线出发，两端断网确认同一笔补款，再分别联网。另一组用例在服务器接收 12 期分期后丢弃响应，重发原操作。 | 补款可手动选择本机或云端金额和月份，双方最终保留同一条明细。分期重试后仍为 12 条。[同步协议](../backend/docs/sync.md) |
| 双端账本回归 | 在 Windows 和 Android 真机使用独立测试账本，录入自定义平台、跨年分期和预计补款。结清平台后补录一笔。在手机上选择一笔跨年分期，先作废本期，再作废整笔，同步到另一端恢复，并用 JSON 备份迁移账本。 | 两端逐期核对明细 ID、金额和还款状态，另一笔同名分期仍有效。后来补录的明细仍待还。取消导入后原账本完整。记录真机型号、应用版本和结果。[已有验收记录](milestones.md#2026-11-21-明细与整笔分期的作废和恢复) |
| M1 应用内桌宠 | 在 Windows 和 Android 验证角色切换、JSON / PNG 卡导入、点按招呼和重启恢复。 | 用同一测试月份比对三个角色的提醒，确认收起提示后换宠仍可继续操作原月份的账本。[桌宠使用与验收](../frontend/docs/pets.md) |
| M2、M3 助手验收 | 在 Windows 和 Android 真机配置测试用 DeepSeek Key，主动解释选中月份，用合成截图验证逐笔保存。核对分期试算中的跨年月和工资覆盖。 | 绘图板每期 32.50 元、连续 6 期，画册尾款的缺失字段留空。断网时仍可手工录单和试算。[AI 验收样例](../frontend/docs/ai-features.md#开发与验收) |

## 后续功能与依赖

- **M4 AI 互动**复用 M2。从账本入口提供用户选定月份的汇总，从宠物发起互动时再接入 M1。用“下个月还完剩多少”核对回复中的金额，并验证取消请求后能继续使用清单。
- **M5 Windows 桌面陪伴**在 M1 的角色和状态稳定后再独立开窗，验证窗口移动、关闭、重开与主账本的关系。安卓继续使用应用内角色。

## 跨模块候选工作

| 方向 | 启动条件与首步 | 验证场景 |
| --- | --- | --- |
| WASM 模板双端性能验证 | 如需评估新的计算实现，可在 Windows 与 Android 上用同一份合成大账本运行模板与 TypeScript 汇总。 | 核对金额与平台明细，分别记录首次加载、数据转换与重复切换月份的耗时。[模板入口](../wasm-lib/README.md) |
| 平台数据采集 | 选定具体数据源及可用的导出或授权读取方式。将记录转换为带来源和外部账单编号的草稿，交由用户核对。 | 同一批记录重复导入时可识别重复项。平台无法匹配或分期金额不明确时可手工补全。[采集契约](../frontend/docs/extensions.md#数据采集脚本) |

系统定时通知与小游戏保留为产品候选。是否启动、预期用户操作及平台差异，可在相应功能进入排期时记录。[客户端路线图](../frontend/docs/roadmap.md)
