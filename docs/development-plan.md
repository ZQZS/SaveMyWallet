# 开发计划

截至 0.7.2，Pi 聊天与账务动作、桌宠与系统提醒、本机续聊、聊天控件折叠和账本还原均已接入。Windows 原生客户端已用隔离账本与模拟模型验证关键流程。近期工作集中在 Android 实体设备上的交互、投递与升级回归，以及 DeepSeek 真实回复和识图效果。[近期交付](milestones.md#近期交付) · [已有验收](milestones.md#当前版本验收)

## 近期工作

| 工作项 | 实施步骤 | 完成时可检查的结果 |
| --- | --- | --- |
| 双端离线同步验收 | 从同一云端基线出发，两端断网确认同一笔补款，再分别联网。另一组用例在服务器接收 12 期分期后丢弃响应，重发原操作。 | 补款可手动选择本机或云端金额和月份，双方最终保留同一条明细。分期重试后仍为 12 条。[同步协议](../backend/docs/sync.md) |
| 双端账本回归 | 在 Windows 和 Android 真机使用独立测试账本，录入自定义平台、跨年分期和预计补款。结清平台后补录一笔。在手机上选择一笔跨年分期，先作废本期，再作废整笔，同步到另一端恢复，并用 JSON 备份迁移账本。 | 两端逐期核对明细 ID、金额和还款状态，另一笔同名分期仍有效。后来补录的明细仍待还。取消导入后原账本完整。记录真机型号、应用版本和结果。[已有验收记录](milestones.md#2026-11-21-明细与整笔分期的作废和恢复) |
| M1 应用内桌宠的实体设备验收 | 在 Android 手机上切换内置角色、导入 JSON / PNG 卡，关闭再打开应用。 | 使用同一测试月份，核对伙伴、开场白及月度提示，验证触屏点按和系统返回。[桌宠使用与验收](../frontend/docs/pets.md) |
| M2、M3 助手验收 | 在 Windows 和 Android 真机配置测试用 DeepSeek Key，主动解释选中月份，用合成截图验证逐笔保存。核对分期试算中的跨年月和工资覆盖。 | 绘图板每期 32.50 元、连续 6 期，画册尾款的缺失字段留空。断网时仍可手工录单和试算。[AI 验收样例](../frontend/docs/ai-features.md#开发与验收) |
| M4 聊天与 Pi 工具 | 在手机以通用助手、菜单角色和桌宠弹窗分别聊天。勾一笔合成账单、收起附件并查待还，再切换对话、输入草稿、退出重开。用测试密钥核对角色口吻及工具选择。 | 回复中的待还和最大一笔与勾选范围相符。取消还款后账单仍待还。重启能续写原草稿，按角色清除后其他角色和通用聊天仍可继续。[聊天使用与数据范围](../frontend/docs/ai-features.md#在聊天里查看勾选的账单) |
| Android 提醒投递 | 用「测试提醒」核对弹窗与系统通知，再创建十分钟间隔和午餐随机时段任务，分别在前台、退出应用、关闭提醒后验证。 | 正常退出后系统通知可送达，回到前台时普通弹窗可补发。过了午餐时段会转到下一次，重新开启会跳过停用期间的提醒。记录系统版本、通知权限和省电设置。[提醒任务与渠道](../frontend/docs/pets.md#桌宠提醒与任务列表) |
| 账本还原与 AI 撤销 | 在隔离账本中确认一次 AI 批量改账，再手动记一笔。分别验证按次撤销、跨日归档与超过七天的清理。 | 撤销保留后来手录的账单。昨天和七天前的整本还原点显示实际日期与预览数量，首次使用之前的日期显示不可用。[还原方式与保留期](../frontend/README.md#自动备份与账本还原) |

## 后续功能与依赖

- **M5 Windows 桌面陪伴**在 M1 的角色和状态稳定后再独立开窗，验证窗口移动、关闭、重开与主账本的关系。安卓继续使用应用内角色。

## 跨模块候选工作

| 方向 | 启动条件与首步 | 验证场景 |
| --- | --- | --- |
| WASM 模板双端性能验证 | 如需评估新的计算实现，可在 Windows 与 Android 上用同一份合成大账本运行模板与 TypeScript 汇总。 | 核对金额与平台明细，分别记录首次加载、数据转换与重复切换月份的耗时。[模板入口](../wasm-lib/README.md) |
| 平台数据采集 | 选定具体数据源及可用的导出或授权读取方式。将记录转换为带来源和外部账单编号的草稿，交由用户核对。 | 同一批记录重复导入时可识别重复项。平台无法匹配或分期金额不明确时可手工补全。[采集契约](../frontend/docs/extensions.md#数据采集脚本) |

桌宠小游戏仍属候选，可复用现有角色素材和互动入口。各阶段的实现范围与依赖见[客户端路线图](../frontend/docs/roadmap.md)。
