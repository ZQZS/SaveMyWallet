# 原生 AI 适配器预留位置

后续在此目录实现用户自带 Key 的凭据访问、供应商 HTTPS 请求，以及用户所选图片的临时句柄。当前 Rust 程序只注册本地账本命令，本目录尚无已注册的 AI 命令。

前端设置界面提交新 Key 后，只需知道配置 ID 和是否已配置。未来的推理命令按配置 ID 加载密钥，返回文案或待审核草稿。诊断消息省略授权头、图片正文、请求及响应正文。取消、完成和凭据移除均需要释放相应资源。接入真实实现时再同步更新命令注册和能力权限。

接口名、能力输入输出以及两端凭据存储方案见 [AI 功能开发说明](../../../docs/ai-features.md) 和 [TypeScript 能力契约](../../../src/integrations/ai/capabilities.ts)。
