# SaveMyWallet 开发路线

用户打开账本时，最关心这个月还有哪些平台要还、下个月要准备多少钱，以及还完后工资能剩多少。桌宠可以为这些提醒提供一个可选入口。AI 可以解释本地汇总、协助读图，减少手工录入。

## 后续候选

- **平台数据采集。** 目标是减少重复录入。选定具体数据源后实现采集器，把来源与外部记录编号交给草稿审核，用重复采集样例验证去重。
- **WASM 模板性能验证。** 评估新实现时，在 Windows 和 Android 上用同一份合成大账本测量首次加载和连续切月的耗时。
- **桌宠小游戏。** 可复用已有角色素材和互动入口。

## 开始下一阶段前

AI 接入使用 `deepseek-flash`。收集脱敏或合成的账单样本，分别记录总额和每期金额的识别结果，以及信息缺失时是否留空。进入验收时记录实际测试的平台、设备和样本。

具体接口与资源示例见[桌宠开发说明](pets.md)、[AI 功能开发说明](ai-features.md)及[已有扩展接口说明](extensions.md)。
