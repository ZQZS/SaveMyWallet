# SaveMyWallet 开发路线

用户打开账本时，最关心这个月还有哪些平台要还、下个月要准备多少钱，以及还完后工资能剩多少。桌宠可以为这些提醒提供一个可选入口。AI 可以解释本地汇总、协助读图，减少手工录入。

## 建议的实施顺序

月度解释和截图识别已接入 DeepSeek，分期试算可在月度账本中使用。M3 已扩展到通知文字和截图的尾款对账。M4 支持从自然语言提取固定的查账条件，也可从桌宠旁打开对话。M2 至 M4 的真实 API 与安卓真机效果待验。

| 里程碑 | 目的与交付范围 | 依赖 | 验收场景 |
| --- | --- | --- | --- |
| M1 · 应用内桌宠 | 选择内置或导入的角色，在月度账本点按招呼、查看提醒 | 本机角色库与月度汇总 | 双端验证开关、卡片导入、重启恢复选择和角色切换后收起的提醒 |
| M2 · 自带密钥与 AI 提醒 | 设置、检测、替换和删除每台设备的 DeepSeek API Key，主动请求所选月份的解释 | 原生凭据存储与本地月度汇总 | 在设备上验证有效密钥、密钥撤销、超时和断网，核对界面中的预计结余和警告线。 |
| M3 · 截图录入与尾款对账 | 用户先预览截图，再核对草稿并逐笔确认入账。收到尾款通知时可提交文字或截图，从本机预计补款中选原单核对。 | M2 的凭据与本地账单表单 | 合成截图覆盖分期和多笔款项。用同名预订核对选单、定金与尾款差额，确认后仅原记录更新。 |
| M4 · AI 互动 | 菜单可选择通用助手或内置、导入的角色，自由聊天。桌宠弹窗和菜单分别保留多段对话，发送时可附月度摘要和指定明细。 | 本机 DeepSeek Key 与 M1 角色资料 | 切换角色并切回，核对草稿、会话及请求中实际发送的人设。减少勾选后核对下次发送的数据范围，验证停止与重新发送。 |
| M5 · Windows 桌面陪伴 | 将应用内已验证的角色放进可关闭的独立桌面窗口；继续复用资源包和互动逻辑 | M1；接入 AI 对话时再依赖 M4 | 验证主窗和宠物窗同时打开、移动到另一显示器、关闭及重新打开；安卓沿用应用内入口，单独验证触控和返回操作 |

## 后续候选

- **平台数据采集。** 目标是减少重复录入。选定具体数据源后实现采集器，把来源与外部记录编号交给草稿审核，用重复采集样例验证去重。
- **WASM 模板性能验证。** 评估新实现时，在 Windows 和 Android 上用同一份合成大账本测量首次加载和连续切月的耗时。
- **桌宠小游戏。** 可复用已有角色素材和互动入口。

## 开始下一阶段前

AI 接入使用 `deepseek-flash`。收集脱敏或合成的账单样本，分别记录总额和每期金额的识别结果，以及信息缺失时是否留空。进入验收时记录实际测试的平台、设备和样本。

具体接口与资源示例见[桌宠开发说明](pets.md)、[AI 功能开发说明](ai-features.md)及[已有扩展接口说明](extensions.md)。
