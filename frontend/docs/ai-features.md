# AI 功能开发说明

目标是让用户更容易理解月度结余、和桌宠作简短交流，以及从账单截图起草多笔还款。0.1.1 已有本地预算预警和手工记账。本次准备了能力接口、提示词、合成识图样例与离线解析测试。供应商适配、凭据设置、消息展示和图片审核页属于后续开发。

## 三个独立入口

| 用户操作 | 交给模型的内容 | 应用接收与处理 |
| --- | --- | --- |
| 查看一条月度提醒 | 选定月份、预计结余、最低结余警告线和已确认仍待还金额 | 月度汇总继续由本地账本计算。模型只生成简短文案，金额和预警状态在界面中使用本地值。文案失败时显示现有预警 |
| 与桌宠交流 | 用户本轮提交的消息，经其选择可附某月的四项汇总值 | 将回复作为纯文本显示。问“下个月还完剩多少”时使用下月的本地预计结余，缺少对应摘要时引导查看。桌宠也可独立使用本地互动 |
| 从图片录入账单 | 用户主动选择并同意发给该供应商的图片 | 生成零条或多条待核对草稿，用户选择平台、补全字段并确认入账 |

前端通过可选的 `AiCapabilities` 调用已配置的能力。`toReminderFacts` 从已算好的月度结果提取表中的四项值，完整平台分组、工资与消费明细保留在本地。互动的可选摘要使用相同的字段，识图传入选定图片的短期标识。模型侧的提示词与合成验收数据独立于 UI。接入时再把实际使用的模板作为本地资源打包。[能力契约](../src/integrations/ai/capabilities.ts) · [提示词](../resources/ai/prompts/)

## 接入用户自己的 API Key

1. 为每个配置保存供应商、模型、可用能力和本地配置 ID。设置页提供录入、替换、移除 Key 的动作。模型调用只传 `profileId`，原生适配器按 ID 取凭据。实际可用的服务、模型和端点在接入阶段确定。
2. 由原生层将密码输入控件提交的值交给系统凭据存储，提交后清空输入。Windows 可使用 Credential Manager。安卓可用 Keystore 管理加密密钥，用它加密 API Key 后将密文保存在应用私有目录。移除配置时一并删除对应凭据或密文。将 Key 保存在设备凭据存储中。源码、面向前端的 `VITE_*` 变量、SQLite 账本、备份和诊断日志均应排除 Key。[原生接入目录](../src-tauri/src/ai/README.md) · [Windows 凭据接口](https://learn.microsoft.com/en-us/windows/win32/api/wincred/nf-wincred-credwritew) · [Android Keystore](https://developer.android.com/privacy-and-security/keystore)
3. 原生适配器根据已保存配置向对应的 HTTPS 服务发送请求。首次启用时说明接收方、会发送的数据和可能产生的模型费用。诊断仅记录能力、耗时和错误类别。密钥失效可更换配置，限流或断网可稍后重试，用户关闭 AI 时回到本地功能。

## 识图审核与写入

1. 未来图片选择器从 Windows 文件对话框或安卓系统图片选择器接收用户选中的图片。原生层预览所选内容并管理临时图片标识，发送前允许取消或改选。请求结束后释放标识与临时文件。
2. 服务端结果在适配器内解码为 JSON，通过 `readBillDrafts` 校验结构。空数组表示未识别到款项，响应格式错误单独报错。看不清的字段用 `null` 表示。分期金额是每期应还金额，仅识别到分期总额时由用户补填。草稿仅保留六个候选字段。[识图草稿解析器](../src/integrations/ai/visionDrafts.ts)
3. 审核页面逐笔将 `platformHint` 与动态平台列表匹配，由用户核对或新建平台，再核对还款月份、金额、类型和期数。识别到的「已还」字样不改变清单状态。可跳过重复明细或取消。确认后复用表单校验，生成 `BillInput` 并走既有写入路径。若后续支持一次确认多笔，应记录每笔提交结果或实现事务，以防重试时重复生成分期。[账单表单](../src/features/bills/components/BillForm.vue) · [账本仓库](../src/data/repository.ts)

## 开发验证

在项目根目录运行 `node --experimental-strip-types --test tests/ai-capabilities.test.mjs`。本地测试检查最小提醒上下文、草稿解析和畸形输出。素材目录提供一张合成账单截图及手工标注的预期 JSON，用于未来识图接入验收。截图中绘图板每期 32.50 元、共 6 期，画册补款则缺少金额和月份。接入供应商后，可发送此图并与预期字段比对，再在两端验证凭据替换/删除、拒绝发图、断网时继续手工录入、供应商错误、取消审核和确认后只写入一次。[合成输入图片](../resources/ai/fixtures/vision-synthetic.png) · [预期草稿](../resources/ai/fixtures/vision-synthetic.json)
