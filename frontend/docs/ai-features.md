# DeepSeek 账本助手

## 首次配置

1. 在 DeepSeek 开放平台创建自己的 API Key，并确认账户有可用余额。SaveMyWallet 使用 `deepseek-flash`，由 DeepSeek 按该账户实际使用的输入和输出 Token 计费，图片也计入输入。[创建 API Key](https://platform.deepseek.com/api_keys) · [官方模型与计费](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)
2. 在 Windows 或安卓客户端打开「系统设置 → 扩展配置 → AI 助手」，粘贴 Key、保存并检测连接。每台设备单独配置。Windows 使用系统凭据管理器，安卓使用 Keystore 保护加密密钥，并将加密后的 API Key 存在应用私有目录。
3. 需要更换 Key 时在同一页保存新值，移除操作会删除本设备保存的凭据。需要在所有使用该密钥的应用中停用它时，到 DeepSeek 开放平台撤销。账本备份和跨设备同步只包含账本数据。[原生接入说明](../src-tauri/src/ai/README.md)

## 使用入口和数据范围

| 功能 | 用户主动发送给 DeepSeek 的内容 | 在本机完成的操作 |
| --- | --- | --- |
| 月度账本中的月度解释 | 选中月份、预计结余、已确认待还金额、最低结余警告线 | TypeScript 计算并显示金额和预警，模型补充简短说明。断网时仍可查看月份汇总。 |
| 统计 → AI 支出用途分析 | 点击「分析支出用途」后发送预览中的款项名称，同名只发送一次。 | 按整个统计区间或图表所选月份汇总金额、笔数和占比。购买游戏、游戏充值归入「游戏娱乐」，角色手办、徽章和立牌等归入「周边」。用途难以判断的款项归入「其他或用途不明」。 |
| 记一笔 → 从截图录入 | 用户预览后确认发送的那张图片，以及手动选择的还款平台名称（如有） | 校验识别结果，可逐笔确认，或为同一平台一键核对并入账。 |
| 月度账本中的分期试算 | 点击「提取条件」时发送本次输入的文字，以及账本选中的月份，用于解释「下个月」 | 根据首还月、每期金额和期数逐月计算预计结余，并与警告线比较。在本机手填条件也能离线试算。 |
| 尾款通知对账 | 本次粘贴并提交的通知文字或预览后提交的截图，以及账本选中的月份 | 从有效的待确认预计补款中选择原单，核对金额和月份的变化，确认后更新原记录。 |
| 一句话查账 | 点击「一句话查账」提交问题时发送问题和账本选中的月份 | 提取成功后自动按条件筛选本机明细，并用整数分汇总。也可手动设置条件后直接查询。 |
| 桌宠聊天 | 消息、当前对话中符合分享范围的近期问答、角色资料与台词样例。默认不附账本，可附月度摘要，或分享摘要和勾选的当月明细。 | 可预览明细、核对并执行业务操作。每个伙伴在每个月可有多段独立对话，各自的草稿和历史仅保留在本次应用会话。[发送字段与提问示例](pets.md#与当前伙伴聊天) |
| 菜单「聊天」 | 本次消息与符合分享范围的近期问答。可选的账本资料与桌宠相同。 | 有独立的对话和草稿，可自由提问、写作，也可勾选账单查待还。 |
| 桌宠弹窗和系统通知 | 已配置 AI 时，生成提醒台词会发送桌宠角色资料、语言及选填的提醒事项。 | 本机保存最终文案并安排提醒。没有配置 AI 或生成失败时使用角色的默认台词。 |

模型请求由原生客户端直接发往 DeepSeek。账本同步后端可以独立部署，使用 AI 助手时无需启动它。DeepSeek 可直接处理截图，应用将本机选择的图片随识别请求发送。[官方图像理解说明](https://api-docs.deepseek.com/zh-cn/guides/vision/)

### 在聊天里查看勾选的账单

从菜单进入「聊天」可直接聊日常话题，例如「帮我把这段话改成一封简短的邮件」。从月度账本点伙伴旁的「聊天」，则由当前角色与你对话。两个入口各自保留会话，均默认选择「不附账本」。

要查账，选好月份，切换到「当月明细」，核对勾选项后发送「我勾选的账单里还有多少没还，最大的是哪一笔？」。Pi Agent Core 的只读工具在本机用整数分计算，并将本轮勾选范围内的结果交给 DeepSeek。比如勾选两笔已确认待还的 80 元、120 元，一笔已还的 300 元和一笔待确认的 50 元，勾选范围内已确认待还为 200 元，最大待还为 120 元。待确认尾款可另外查看。

每次发送前都可以更改分享范围。「月度摘要」里的已确认待还是整月金额。问勾选项时，工具按此次选择计算。撤掉勾选后，下次发送也会截去涉及这些明细的旧问答。本机仍可翻看先前的对话。[桌宠聊天与明细分享](pets.md#与当前伙伴聊天)

### 在聊天里改账

桌宠和菜单「聊天」均可办理下列账务操作。对已有账单，先在「当月明细」核对本轮勾选的编号。助手提出修改后，窗口会显示本机账本中的实际条目、金额和改动范围。点确认才会写入，点取消可保留原记录。

| 想做的事 | 可以怎么说 |
| --- | --- |
| 标记还款、改回待还、撤销上次还款操作 | 「把勾选的第 1、3 笔标记为已还。」撤销上次操作时，勾选当时实际变更的账单。 |
| 确认预计补款 | 「把勾选的画册尾款改为 80 元，在 12 月确认。」确认会更新原记录，默认沿用已付定金。 |
| 作废或恢复 | 「只作废这一期。」若想处理整笔分期，明确说「作废整笔分期」，并在预览中核对跨月的各期。恢复时先显示并勾选已作废的账单。 |
| 新增账单或还款平台 | 「在花呗记一笔耳机分期，从 2026 年 12 月开始，每期 80 元，共 3 期。」也支持单次账单、预计补款和新增还款平台。 |
| 调整工资或警告线 | 「把这个月的工资改为 6000 元」或「把最低结余警告线调到 800 元」。工资可按月覆盖，警告线是全局设置。 |

账本若在预览后发生与该操作有关的变化，需要按新内容再核对。写入成功后即使刷新失败，也只需重新读取账本。聊天中的还款操作记录实际还款状态，资金支付仍由用户在相应平台完成。

### 在聊天里安排提醒

在桌宠或菜单聊天中说「十分钟后发系统通知提醒我核对尾款」或「每月 10 号上午 9 点通知我还款」，无需分享账本。聊天支持单次、每天、每周和每月提醒。两个入口都使用设备本地时间，确认卡会列出事项、渠道，并在有重复规则时显示规则和下次时间。「还款」是提醒事项，确认这条通知不会改变账单的还款状态。

也可以只说「每天晚上八点让桌宠弹一下」，让角色决定说什么。应用关闭期间错过的桌宠弹窗会在下次打开时补弹，系统通知可在应用关闭时送达。设置中的「提醒任务」可以查看、修改或取消聊天创建的任务。[桌宠提醒与任务列表](pets.md#桌宠提醒与任务列表)

### 核对截图草稿

单张截图支持 PNG、JPEG 或 WebP，最大 8 MiB。选图后先核对预览，发送前可换图或取消。「还款平台」默认为「自动识别」，也可以选择账本中已有的平台。手动选择的平台会预填到这张截图的每笔草稿里，核对时可以逐笔修改。

长截图可以上下滚动查看。发送时，客户端在本机将长图切成略有重叠的连续图段，按顺序放进同一次识别请求。每个图段都会计入图片用量。[DeepSeek 图片用量说明](https://api-docs.deepseek.com/zh-cn/guides/vision/#token-用量)

例如在 2026 年 11 月的账本导入花呗「12月总计账单」，本期归入 2026 年 12 月。账单标题省略年份时，本机用所选账本月份及其前后各一个月判断。「第2/3期」会生成 12 月的第 2 期和次年 1 月的第 3 期，后续各期沿用截图中的每期金额。末期只生成当前这一笔。本期仍列正金额的商品按右侧金额计入，包括附有「有退款，已退至其他月份账单」的分期。退款到账金额以对应月份的实际账单为准。

核对页会加总所有明细的本期金额，再与截图页首的账单总额核对。每笔分期只计本期一次。为截图选定平台后，可点「全选待入账明细」，也可单独勾选。页面按月显示勾选小计。核对无误后点「确认勾选的 … 笔并入账」，其余待入账明细可继续勾选，分批保存。整张截图的总额始终按全部明细核对。合计有差额或月账单总额无法读取时，可以展开原图逐笔核对并入账。

重复导入支付宝、花呗截图或其他平台的月账单时，核对页按平台、还款月份、名称、类型和本期金额逐笔匹配账本，分期另核对当前期数和总期数。已还和待还明细都参与匹配。每笔已有明细只对应截图中的一行。例如账本已有 A，新截图出现 A、A、B，批量入账会跳过一个 A，新增另一个 A 和 B。点「核对」可查看匹配的原记录，确认是另一笔消费时可单独入账。若名称或金额识别有误，可先修正再核对，点「跳过这笔」也会保留此次核对的修正。

识别出多笔款项时，逐笔核对平台、名称、还款月份、金额、类型和期数。**分期填写每期应还金额**。分期图片只列总价、月份不清或平台无法匹配时，手工补全对应字段。提交前核对起止月份，并跳过已经录入的款项。点击「确认这笔并入账」会保存当前这笔，结束核对时已确认的账单保留在账本中。[草稿校验](../src/integrations/ai/visionDrafts.ts) · [账单表单](../src/features/bills/components/BillForm.vue)

预计补款按总价减去已支付定金计算。截图只列尾款时，审核页显示识别到的尾款供核对，请补填总价和实际已付定金。若截图同时列出尾款与已付定金，审核页会预填两者之和作为总价。截图金额相互矛盾时，核对原图后可修改再保存。

在「待开补款」订单列表中，每张卡片顶部的「预计2026.11到货补款」会为该笔草稿预填 2026 年 11 月。若只标注预计到货时间，补款月份留给你核对填写。

### 尾款通知对账

在月度账本打开「尾款通知对账」，粘贴商家的尾款通知，或选择并预览一张通知截图。发送后查看提取出的款项，再从本机候选记录中选中原单。若有多笔同名预订，用平台、月份和原金额区分。核对新月份、总价、已付定金和应补差额后再确认。确认沿用原明细 ID，取消审核会保留原单。

例如原先记录画册总价 100 元、定金 20 元、应补 80 元。通知写「画册下月补 100 元」，核对时沿用原定金 20 元，显示新总价 120 元、应补比原来多 20 元。通知与原定金不符或金额相互矛盾时，按原始单据核实后填写。已付全款且应补为 0 元的原单，确认后直接结清。

### 一句话查账

在月度账本打开「一句话查账」，试着问「下个月有哪些付过定金、还需要补款的订单？」。例如在 11 月账本提问，「下个月」指 12 月。提取成功后，页面自动列出匹配的本机明细，分别汇总预计补款与已确认待还，金额已扣除定金。可以核对月份、定金和还款条件，或加上平台名与款项名称，再点「在本机查询」刷新结果。选择包含作废记录时，金额合计只计有效明细。

点一笔结果会切到对应月份、展开平台并定位明细。用返回键可以继续查看同一组结果，沿用原问题的参考月份，也无需再次调用 DeepSeek。

### 分期试算

例如在月度账本输入「如果下个月开始每期增加 200 元、共 6 期，哪些月会低于警告线？」。核对识别出的首还月、金额和期数，点击「在本机试算」查看逐月结果，也可以直接修改这三个字段。每个月先按当月工资和已有账单得到原预计结余，再减去新增的一期金额，得出试算后的预计结余。已作废的明细沿用月度汇总规则排除。决定记账时，点「按此方案记一笔」打开预填的分期表单，补齐平台、名称并确认保存。[本地月度汇总](../src/domain/ledger.ts)

## 开发与验收

在 `frontend/` 运行 `npm test`、`npm run build` 以及 `cargo test --manifest-path src-tauri/Cargo.toml --lib`。离线测试覆盖本地汇总、模型输入输出校验等逻辑。验证真实模型的识别效果时，使用自己的测试 Key 和隔离账本，在「记一笔」选取下方合成截图。

- 绘图板应识别为 2027 年 1 月起每期 32.50 元、共 6 期。确认后，2027 年 1 月至 6 月各出现一笔 32.50 元。
- 画册尾款缺少月份和金额，应留给用户补填。跳过该笔后，账本中应只有已确认的绘图板分期。
- 在设备上检查换图、取消、密钥替换与删除，以及断网时手工试算和记账。真实 API 的识别准确率及 Android 真机体验需要分别实测。[合成输入图片](../resources/ai/fixtures/vision-synthetic.png) · [预期草稿](../resources/ai/fixtures/vision-synthetic.json)
