# 应用内桌宠与酒馆角色卡

在「系统设置 → 扩展配置 → 桌宠」开启「在月度账本显示桌宠」，回到月度账本即可点它打招呼。钱包猫说话温和，账房鸮偏爱短句，侦探狐喜欢追问线索。点角色旁的「换伙伴」或回到设置，可以先看各自的台词，再选一个伙伴。本机会记住开关和所选角色。

桌宠读取所选月份的账本汇总。预计结余低于警告线时，它会提示差额。有待确认的预计补款时，可从提示查看月度明细，也可以在聊天里核对后确认。换角色会保留当前月份和已收起的提示。

## 与当前伙伴聊天

在「系统设置 → 扩展配置 → AI 助手」保存并检测本机的 DeepSeek API Key。回到月度账本，点击当前伙伴旁的「聊天」，输入问题后点「发送」。内置角色和导入的酒馆角色都可以聊天。点角色打招呼、换伙伴和查看桌宠提醒仍可离线使用。[AI 助手配置](ai-features.md#首次配置)

菜单里的「聊天」另有角色选择器。默认的「通用聊天」使用普通助手身份，也可以直接选一只伙伴，按它的口吻聊工作、写作、游戏或你感兴趣的话题。每个选择各有草稿和对话历史。菜单会记住上次选择，月度账本继续使用桌宠设置中选中的伙伴。

想换个话题时，点「新建聊天」。已有空白聊天时会直接打开它。在「当前聊天」里可以切回同一伙伴、同一月份的其他对话。每段对话有独立的输入草稿和问答记录，关闭再打开可以继续。移除导入角色会清除该角色所有月份的聊天。刷新页面或重启应用会清除所有临时聊天记录。

点击「发送」后，DeepSeek 会收到本次消息、角色名字、描述与性格、开场白节选和一段说话样例。应用最多附上当前对话最近五轮符合本次分享范围的问答。每次发送前都可以选择以下账本资料。

| 随消息发送 | 账本资料 | 可以怎么问 |
| --- | --- | --- |
| 不附账本（默认） | 本次只发送聊天所需内容。 | 「核对账单时，你习惯先看什么？」 |
| 月度摘要 | 所选月份、预计结余、最低结余警告线和已确认待还金额。 | 「这个月还款后预计剩多少，距离警告线还有多少？」 |
| 当月明细 | 上述四项摘要。伙伴查询明细时，还会收到本次勾选的账单和本机计算的结果。 | 「勾选的账单还有多少没还，最大待还是哪一笔？」 |

首次选「当月明细」时，预览会勾选本月所有有效账单。发送前可逐笔增减，核对条目、编号和笔数。月度摘要始终汇总整月。勾选的明细包含平台、账单名称、类型、状态和金额。预计补款列出应补尾款和已付定金。分期列出本期金额和期次。要恢复作废账单，先显示已作废账单，再逐笔勾选。作废项不计入待还合计。账单与平台的内部 ID 仅在本机使用。

取消部分勾选、切回「月度摘要」或「不附账本」后，应用会截去涉及已撤选资料的历史上下文，本机仍可查看先前对话。请伙伴改账时，在聊天中核对受影响的账单及金额，点击确认后才会保存。[聊天中的账务操作](ai-features.md#在聊天里改账)

## 桌宠提醒与任务列表

在「系统设置 → 扩展配置 → 提醒任务」新建提醒，选择桌宠弹窗或系统通知。填好事项后，可以先点「测试提醒」，立即体验所选渠道和桌宠台词。测试独立于任务列表，表单仍可继续修改。事项也可以留空，由桌宠决定说什么。

| 想怎样提醒 | 设置方法 |
| --- | --- |
| 20 分钟后提醒一次 | 选择单次提醒，选 20 分钟后。也可以指定日期和时间。 |
| 每隔 30 分钟提醒喝水 | 选择「每隔几分钟」，填 30。间隔支持 10 分钟的整数倍，最长 31 天，从首次提醒起计算。 |
| 饭点或睡前随机提醒 | 选择「每天在时段内随机提醒」。午餐预设为 11:30–13:00，睡前为 22:00–23:00。起止时间和事项都可改，也支持 23:30 到次日 00:30 这样的跨午夜时段。 |
| 每月 10 日上午 9 点提醒还款 | 选择「每月」、10 日、09:00，填写「还款」。每天和每周也可以指定本地时间。 |

每个随机时段只选一个提醒分钟，列表会显示下次时间。关闭再打开应用会沿用已选时间。错过整个时段时会跳到下一个时段，例如晚饭后打开应用时不会再补发午餐提醒。

每条定时任务都有开关。关闭会暂停弹窗或撤下系统排程，保留事项、渠道和重复规则，仍可编辑。重新开启重复提醒时，从规则里的下一个时间继续，暂停期间的提醒直接跳过。一次性提醒的时间已经过去时，重新选一个未来时间即可再次开启。选择「删除」并确认后，会移除任务及其后续提醒。

例如周末可以先关闭「吃午饭」，周一再开启。每月 29 至 31 日的任务会跳过没有该日期的月份，例如每月 31 日的任务在 4 月跳过，下一次是 5 月 31 日。

| 渠道 | 何时看到 |
| --- | --- |
| 桌宠弹窗 | 在应用里显示。到点时应用已关闭或处于后台，普通定时提醒在下次回到前台时补弹，同一任务最多补一次。随机提醒只在所选时段内补弹。 |
| 系统通知 | 由设备的通知系统投递，正常退出应用后仍可提醒。请允许应用发送通知。Windows 需要用户已登录，安卓的省电策略可能推迟送达，免打扰设置也会影响提示方式。 |

Windows 关机或注销期间错过的单次系统通知，计划会保留七天供下次登录时补发。安卓若在系统设置里强行停止应用，需要重新打开应用才能恢复提醒。

任务沿用创建时选中的桌宠。没有配置 AI 时使用本机台词，配置 DeepSeek 后可提前根据角色描述和说话样例生成文案。填了具体事项时会保留原文。重复任务每次使用已保存的台词，离线也能提醒。仅修改提醒时间或重复规则会沿用原文案。

两个聊天入口也能创建提醒，例如「每 20 分钟弹窗提醒我站起来」「每天晚上 10 点到 11 点之间随机通知我睡觉」「每月 10 号上午 9 点通知我还款」。核对渠道、重复规则、下次时间和事项，点「确认执行」后创建。

## 从酒馆导入角色

点「导入酒馆角色卡」，从设备中选取文件。导入成功后，新角色成为当前伙伴。移除当前使用的导入角色后，钱包猫会接替它。想在另一台设备使用同一角色，在那台设备上导入原卡即可。角色卡独立保存在设备上，账本的 JSON 备份和跨设备同步只处理账本数据。

| 文件 | 可读取的内容 |
| --- | --- |
| 酒馆 V1 JSON | 从顶层读取名称、描述、性格、场景、开场白与对话示例。 |
| Character Card V2 / V3 JSON | 从 `data` 读取角色资料，也支持 `alternate_greetings` 中的备选开场白。JSON 导入的角色使用名称首字作头像。 |
| 酒馆 PNG 卡 | 读取 `tEXt` 中的 `chara` 或 `ccv3` 角色数据，用 PNG 图像作静态头像。两个字段同时存在时，优先取 `ccv3`。请使用从酒馆导出的原始卡片，截图或重新压缩的图片可能丢失角色数据。 |

单张卡的文件大小上限为 16 MiB。PNG 的宽和高均须在 8,192 像素以内，总像素数最多为 16,777,216。应用在本机提取静态头像，按原比例缩放到最长边 256 像素以内，将头像和角色资料保存在 WebView 的 IndexedDB 中。

角色选择器展示导入资料，点按角色时使用卡内开场白。菜单角色聊天可参考新导入卡的 `scenario` 场景和 `mes_example` 对话样例。已有角色可以继续使用。若想使用旧版导入时没有保存的场景或长样例，可以重新导入原卡并选用新角色。应用只读取支持的角色资料，世界书、脚本和卡内系统提示词不参与聊天。格式字段可参阅 [V1 定义](https://github.com/malfoyslastname/character-card-spec-v2/blob/main/spec_v1.md)、[V2 定义](https://github.com/malfoyslastname/character-card-spec-v2/blob/main/spec_v2.md)和 [V3 定义](https://github.com/kwaroran/character-card-spec-v3/blob/main/SPEC_V3.md)。

## 维护内置角色

每只内置角色在 `resources/pets/<id>/` 下提供图包和中英文 `lines.json`。清单以目录名作为稳定的 `id`，记录显示名、素材来源和相对图像路径。展示组件使用待机图 `idle` 和可选的招呼图 `greet`，缺省时显示待机图。可复制钱包猫目录，更新素材和台词，再将新角色加入 `catalog.ts` 中的 `packs`。[钱包猫图包](../resources/pets/wallet-cat/) · [动作清单](../src/features/pets/manifest.ts) · [内置角色目录](../src/features/pets/catalog.ts)

在 `frontend/` 运行 `npm test` 检查角色资源和导入解析，运行 `npm run build` 检查组件、类型和打包。双端验收时可分别用内置角色和导入卡新建聊天，检查每段对话的草稿与历史，再用隔离账本更换分享范围，核对回复中涉及的月份、明细和金额。[客户端路线图](roadmap.md)
